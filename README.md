# 魔王夜宴 Soirée Noire

3 到 7 人的回合制联机小游戏：每人轮流当一次魔王，魔王布阵、指挥怪物，其余的人当勇者一路打穿，最后比总分。

这个仓库只放安装包和自动更新用的版本清单，没有源码。

## 第一次玩

1. 打开 [最新版本](https://github.com/Komari-chan/soiree-noire-release/releases/latest)，下载 `SoireeNoire-<版本>.zip`。
2. 解压到自己的文件夹（别放在 Program Files 里，不然没法自动更新）。
3. 双击 `SoireeNoire.exe`。Windows 提示「已保护你的电脑」时点「更多信息 → 仍要运行」。

## 之后

每次打开游戏会自己检查新版本，有更新就在标题页下载，下好后自动重启。房主和大家版本不一样时进不了房间，重开游戏更新就好。

## 开房

标题页点「开房间」，把房间码发给朋友；朋友输入房间码点「加入」。
